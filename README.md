## 👋 자기소개
Unity와 C#을 기반으로 약 4년간 개인 및 팀 프로젝트를 진행하며 다양한 개발 경험을 쌓았습니다.<br>
TPS 로그라이크 게임을 중심으로 전투, AI, 상태 관리, UI 등 주요 시스템을 구현했으며, 기능 확장과 유지보수를 고려한 코드 구조 개선도 경험했습니다.<br>
이후 Android 애플리케이션, 외부 API 연동, 강화학습 시뮬레이션 등으로 개발 범위를 넓히며 새로운 기술을 실제 프로젝트에 적용해 왔습니다.

## 1. TPS 로그라이크 게임
**📅 기간:** 2022.09.20 ~ 2025.03.01 (Unity 학습 기간 포함)<br>
**🧑‍💻 역할:** 기획, 프로그래밍<br>
**👥 팀:** 프로그래머 1인, 디자이너 1인<br><br>
[![영상보기](https://img.youtube.com/vi/JgRZtCDci7s/0.jpg)](https://www.youtube.com/watch?v=JgRZtCDci7s)

**💻 GitHub Repository**: [프로젝트](https://github.com/choiminjun-coder/ShootingStar)<br><br>
### 📝 개요
Unity와 C#을 학습하며 진행한 3D TPS 로그라이크 프로젝트로, 이후 진행한 여러 개발 프로젝트의 기술적 기반이 되었습니다.<br><br>

### ⚙️ 개발 과정
- **전투 시스템:** 캐릭터 이동, 근·원거리 무기 전환, Raycast 기반 공격 및 Animator 연동
- **적 AI:** FSM을 활용한 행동 상태 관리와 NavMesh 기반 이동 구현
- **게임 시스템:** 아이템, 상태이상 효과, UI 등 게임플레이 기능 구현
- **코드 구조:** 기능이 늘어나는 과정에서 역할별로 코드를 분리하고 모듈화

<br>

### 🔧 개발 경험
Unity의 입력, 상태 관리, AI, 애니메이션 등 주요 기능을 직접 구현하며 시스템 간 연동과 코드 구조에 대한 이해를 쌓았습니다.<br>
이후 협업, 외부 API 연동, Android 개발 및 시뮬레이션 프로젝트로 경험을 확장하는 기반이 되었습니다.<br><br>

## 2. 퍼즐 게임

**📅 기간:** 2024.03.01 ~ 2024.10.31<br>
**🧑‍💻 역할:** 프로그래밍<br>
**👥 팀:** 3인 팀 (프로그래머 2인)<br><br>

**💻 GitHub Repository:** [프로젝트](https://github.com/choiminjun-coder/puzzle-game)<br><br>

### 📝 개요
색상과 객체 상태에 따라 퍼즐의 진행과 결과가 달라지는 Unity 기반 팀 프로젝트로, 조건 판정과 오브젝트 상호작용을 구현했습니다.<br><br>

### ⚙️ 개발 과정
- **퍼즐 로직:** 색상 및 객체 상태 조건에 따른 퍼즐 진행과 클리어 판정 구현
- **객체 상호작용:** 사용자 입력에 따른 상태 변화와 Physics 기반 물리 상호작용 구현
- **애니메이션 연동:** Animator를 활용해 객체 상태에 따른 동작 변화 구현
- **협업:** GitHub 기반 버전 관리, 기능 분담 및 코드 피드백 진행

<br>

### 🔧 개발 경험
다양한 조건과 객체 상태를 조합해 퍼즐 로직을 구성하며, 사용자 입력부터 상태 변화와 결과 판정까지 연결하는 경험을 쌓았습니다.<br>
또한 Github통해 다른 프로그래머와 기능을 분담하고 코드를 연동하면서 협업 및 문제 해결 과정을 경험했습니다.<br><br>

## 4. MIO: Akihabara AI Talk

**📅 기간:** 2026.08.03 ~ 2026.08.05<br>
**🧑‍💻 역할:** 기획, 프로그래밍<br>
**👥 팀:** 개인 프로젝트<br>
**🎯 목적:** 게임잡 참가를 위한 단기 개발 프로젝트<br><br>

**🎬 개발 및 구현 영상:**<br>
[![영상보기](https://img.youtube.com/vi/uR3xFIhhQsY/0.jpg)](https://www.youtube.com/watch?v=uR3xFIhhQsY)

**💻 GitHub Repository:** [Source Code](https://github.com/Choi-Min-Jun-1/MIO_Akihabara_AI_Talk_Source) | [Android APK](https://github.com/Choi-Min-Jun-1/MIO_Akihabara_AI_Talk_Apk)<br><br>

### 📝 개요
게임잡 참가를 위해 짧은 기간 동안 제작한 Unity 기반 Android 3D 프로젝트입니다. 사용자가 입력한 문장에 AI NPC가 응답하고, 생성된 대사를 음성으로 출력하는 기능을 구현했습니다.<br><br>

2025년 진행한 NPC 대화·음악 생성 실험에서 얻은 외부 API 연동 경험을 바탕으로, Android 환경에서 실제 실행 가능한 애플리케이션으로 개발 범위를 확장했습니다.<br><br>

### ⚙️ 개발 과정
- **3D 환경 및 상호작용:** Unity 기반 캐릭터 이동, NPC 상호작용 및 대화 입력 UI 구현
- **AI 대화 및 음성 출력:** Gemini API로 NPC 대사를 생성하고, Google Cloud Text-to-Speech를 연동해 음성으로 재생
- **API 연동 구조:** Google Apps Script를 Gateway로 구성하여 Unity 클라이언트와 외부 AI 서비스의 요청·응답 경로 분리
- **Android 실행 검증:** APK 빌드 후 이동, 대화 입력, AI 응답 및 음성 재생까지 전체 기능 확인

<br>

### 🔧 개발 경험
기존 AI 연동 실험에서 익힌 기술을 활용해 제한된 개발 기간 안에 Android 애플리케이션을 구현했습니다.<br>
외부 서비스 연동부터 클라이언트 기능 구현, APK 빌드와 동작 검증까지 직접 진행하며 새로운 환경에서도 개발을 이어가는 경험을 쌓았습니다.<br><br>

### 🔬 선행 기술 실험: NPC 대화·음악 생성 시스템

**📅 기간:** 2025.11.17 ~ 2025.11.21<br>
**🧑‍💻 역할:** 기획, 프로그래밍 (개인 프로젝트)<br><br>

MIO에 앞서 Unity와 Gemini API, MusicGen Server를 연동하여 사용자의 입력에 따라 NPC 대사와 배경음악을 생성·재생하는 시스템을 개발했습니다.<br>
Coroutine 기반 비동기 처리를 활용해 외부 서비스의 응답을 Unity 실행 환경에 반영하는 흐름을 구성했습니다.<br><br>
